# 🔥 خادم باتل رويال (Node.js + WebSocket)

خادم بسيط يزامن لاعبين أونلاين: يبث مواضعهم وحركتهم وإطلاق نيرانهم وإصاباتهم لحظيًا بين جميع المتصلين بنفس "الغرفة".

## 📦 المتطلبات
- [Node.js](https://nodejs.org) نسخة 18 أو أحدث (مثبّت على جهازك)

## ▶️ التشغيل محليًا
1. افتح الطرفية (Terminal / CMD) داخل مجلد المشروع
2. ثبّت الاعتماديات:
   ```bash
   npm install
   ```
3. شغّل الخادم:
   ```bash
   npm start
   ```
4. راح تشوف رسالة تؤكد إنه يعمل على:
   ```
   ws://localhost:3000
   ```
5. افتح ملف `test-client.html` بالمتصفح (دبل-كليك عليه) لتجرب الاتصال والتأكد إن كل شي يشتغل، قبل ربطه باللعبة الحقيقية.

> ⚠️ وهو شغال محليًا، بس الأجهزة الموجودة بنفس شبكتك (الواي فاي) تقدر توصل له عن طريق IP جهازك بدل `localhost` (مثلاً `ws://192.168.1.5:3000`). للاتصال من الإنترنت العام، لازم تنشره (الخطوة التالية).

## 🌍 النشر للحصول على رابط عام (مجاني)
عشان أي حد بالعالم يقدر يتصل باللعبة، تحتاج تستضيف الخادم. أسهل الخيارات المجانية:

### الخيار الأول: Render.com
1. أنشئ حساب على [render.com](https://render.com)
2. ارفع هذا المجلد كـ repository على GitHub
3. من لوحة Render: **New → Web Service** → اختر الـ repo
4. Build Command: `npm install`
5. Start Command: `npm start`
6. بعد النشر راح يعطيك رابط زي: `https://your-app.onrender.com`
7. عنوان الـ WebSocket يصير: `wss://your-app.onrender.com`

### الخيار الثاني: Railway.app أو Fly.io
نفس الفكرة تقريبًا — ترفع الكود، تحدد Start Command بـ `npm start`، وتحصل على رابط عام.

> 💡 لاحظ إن الرابط بالإنتاج يبدأ بـ `wss://` (آمن) مو `ws://`.

## 📡 بروتوكول الرسائل (JSON)
رسائل يرسلها العميل (Client → Server):

| النوع (type) | البيانات | الوصف |
|---|---|---|
| `join` | `{room, name}` | الانضمام لغرفة باسم معيّن |
| `state` | `{x,y,z,rotY}` | تحديث الموضع والاتجاه |
| `shoot` | `{x,z,vx,vz,weapon}` | إطلاق رصاصة |
| `hit` | `{targetId, damage}` | إبلاغ بإصابة لاعب آخر |
| `chat` | `{text}` | رسالة دردشة |

رسائل يرسلها الخادم (Server → Client):

| النوع (type) | البيانات | الوصف |
|---|---|---|
| `welcome` | `{id, players[]}` | تأكيد الانضمام + قائمة اللاعبين الحاليين |
| `player_joined` | `{id, name}` | انضمام لاعب جديد |
| `player_left` | `{id}` | مغادرة لاعب |
| `state` | `{id,x,y,z,rotY}` | تحديث موضع لاعب آخر |
| `shoot` | `{id,x,z,vx,vz,weapon}` | لاعب آخر أطلق النار |
| `hit` | `{sourceId,targetId,hp,alive}` | نتيجة إصابة (صحية محدّثة) |
| `chat` | `{id,name,text}` | رسالة دردشة من لاعب آخر |

## 🔗 الخطوة التالية: ربطه باللعبة
هذا المشروع هو "الأنبوب" اللي ينقل بيانات اللاعبين فقط. لازم نعدّل كود لعبة الـ 3D (الآرتيفاكت) عشان:
- يتصل بـ WebSocket عند الدخول
- يرسل موضعه كل فريم (`state`)
- يرسم اللاعبين الآخرين بدل/بجانب البوتات
- يرسل وبستقبل أحداث `shoot` و `hit`

قلّي متى تبيني أسوي هذا الربط وأبنيه داخل اللعبة.
